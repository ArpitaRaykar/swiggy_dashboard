# Swiggy Excel Dashboard Analysis

## 📌 Description
This project presents an interactive Swiggy sales dashboard built using Microsoft Excel.  
It analyzes key business metrics such as total sales, orders, ratings, and order value.  
The dashboard helps understand customer behavior, sales performance, and regional trends.

## 📊 Dashboard Preview
![Dashboard](dashboard.png)

## 🛠️ Tools Used
- Microsoft Excel
- Pivot Tables
- Charts
- Slicers

## 📈 Key Insights
- Total Sales reached ₹53M with strong monthly growth trends  
- Highest sales observed in top cities like Bengaluru and Lucknow  
- Average rating maintained at 4.34 indicating good customer satisfaction  
- Peak orders observed on weekends compared to weekdays  
- Regional analysis shows higher revenue contribution from specific states  

## 📊 Features of Dashboard
- KPI Cards (Sales, Orders, Ratings, Avg Order Value)  
- Monthly & Daily Sales Trends  
- Sales by Food Type (Veg vs Non-Veg)  
- State-wise Revenue Analysis (Map)  
- Top Cities by Sales  
- Interactive Filters (Month, State, Restaurant)

## 📁 Dataset
Dataset is available in the `data/swiggy_data.csv` file.

## ▶️ How to Use
1. Download the Excel file  
2. Open `dashboard/swiggy_dashboard.xlsx`  
3. Use filters and slicers to explore the dashboard
